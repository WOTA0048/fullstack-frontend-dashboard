# fullstack-frontend-dashboard

Data visualization using Fetch API.
Has dynamic DOM manipulation, real-time UI state rendering, and integration with FastAPI relational database system.

# setup

Backend server required to run

1. Clone and run the backend repository: https://github.com/WOTA0048/fastapi-relational-database
2. Ensure the Uvicorn server is active at `http://127.0.0.1:8000/docs`
3. Launch `index.html` in your browser to interact with the live synchronized data stream.
